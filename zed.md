# Editing Files on the Raspberry Pi with Zed

Once you have configured SSH access to your Raspberry Pi, you can edit files directly from your computer using Zed.

Zed's **Remote Development** feature lets you:

- Browse files on the Raspberry Pi
- Edit files using a local graphical editor
- Open a terminal on the Raspberry Pi
- Use Git directly on the Raspberry Pi

All communication happens over SSH.

## Prerequisites

- Zed installed on your computer
- SSH access to the Raspberry Pi
